========================================
IMPORTANT NOTES
========================================

⚠️ API Calls:
The frontend pages contain JavaScript code that makes API calls to:
http://localhost:8000/api/

These calls will NOT work without a backend. You need to:
1. Create your own backend (PHP, Node.js, Python, etc.)
2. Update the API URLs in the JavaScript code
3. Implement the required endpoints

⚠️ Authentication:
The pages use localStorage to store session_key:
localStorage.getItem('session_key')
localStorage.setItem('session_key', key)

You'll need to implement this in your backend.
